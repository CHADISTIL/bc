حسابات Cloudflare R2

أضف كل حساب جديد هنا، وفعّل واحداً فقط يُرفع إليه الآن. عند امتلاء حساب أضف حساباً جديداً وفعّله؛ روابط الفيديوهات القديمة تبقى تعمل لأن كل رابط يحمل عنوان حسابه.

المفاتيح تُحفظ في Firestore ويقرأها المشرفون فقط (قاعدة storage). استعمل مفتاح API محصوراً بحاوية واحدة بصلاحية Object Read & Write.
إعلانات VAST

تتحكم في ظهور الإعلانات داخل مشغّل الفيديو.

إن لم يُرجع الرابط إعلاناً يُجرَّب الرابط التالي تلقائياً (حتى 3 روابط).

الأنمي = رسوم متحركة يابانية (تصنيف Animation + لغة أصلية يابانية). التريلر لا يظهر فيه إعلان أبداً.

تُحدَّد الدولة من وركر sp-media (مسار /geo). إن تعذّر تحديدها يظهر الإعلان ولا يُحجب.

إن لم يبدأ الإعلان خلال المهلة يُتجاوز ويكمل الفيديو دون تعطيل المشاهد.
